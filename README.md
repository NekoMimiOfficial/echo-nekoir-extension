# Nekoir3 Echo Extension  
![Nekoir](http://nekomimi.tilde.team/pool/05/nekoir.png)   
Echo3 Neko Choir extension that provides a HI-RES audio streaming option free of charge*  
This extension gives you a barebones music streaming support in this current stage

# Installation  
Install the apk provided in the Releases  

# Building  
- Make sure you have gradle and Java17 installed along with your Android SDK and that you have targets 29 and 34  
- run `./man_build`  
- alternatively run `./fd` for a fast build n deploy
